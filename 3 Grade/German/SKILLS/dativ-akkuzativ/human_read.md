# Dativ + Akkusativ — перед тестом

В этих заданиях: **Dativ = кому?**, **Akkusativ = что?** Падеж определяй по смыслу, а не по позиции в условии.

## Артикли и местоимения

| Род / число | Nominativ | Dativ   | Местоимение DAT | Akkusativ | Местоимение AKK |
| ----------- | --------- | ------- | --------------- | --------- | --------------- |
| Мужской     | der       | **dem** | **ihm**         | **den**   | **ihn**         |
| Женский     | die       | **der** | **ihr**         | die       | **sie**         |
| Средний     | das       | **dem** | **ihm**         | das       | **es**          |
| **Plural**  | die       | **den** | **ihnen**       | die       | **sie**         |
|             |           |         |                 |           |                 |

## Притяжательные и ein

| Род / число | NOM | DAT | AKK |
|---|---|---|---|
| Мужской | mein | **meinem** | **meinen** |
| Женский | meine | **meiner** | meine |
| Средний | mein | **meinem** | mein |
| **Plural** | meine | **meinen** | meine |

У `dein, sein, ihr, unser, euer, Ihr, kein` те же окончания. Особенность: `euer → eure, eurem, eurer, euren`. У `ein` окончания как у `mein`, но **нет множественного числа**.

## Plural — что менять

**AKK:** форма множественного числа не меняется.  
**DAT:** меняем артикль + обычно добавляем существительному **-n**. Если уже заканчивается на **-n / -s**, не добавляем.

| NOM = AKK | DAT |
|---|---|
| die Freunde | **den Freunden** |
| die Kinder | **den Kindern** |
| die Lehrer | **den Lehrern** |
| meine Bücher | **meinen Büchern** |
| unsere Großeltern | **unseren Großeltern** |
| die Frauen | **den Frauen** |
| die Fotos | **den Fotos** |
| meine Autos | **meinen Autos** |

### Артикли во множественном числе

| NOM = AKK | DAT         |
| --------- | ----------- |
| die       | **den**     |
| meine     | **meinen**  |
| deine     | **deinen**  |
| seine     | **seinen**  |
| ihre      | **ihren**   |
| unsere    | **unseren** |
| eure      | **euren**   |
| keine     | **keinen**  |

**Запомни:** `die Fotos → sie` (их), `unseren Großeltern → ihnen` (им). Даже без добавочного **-n** у существительного артикль в DAT меняется!

## Порядок дополнений

| Что стоит в предложении | Порядок | Пример |
|---|---|---|
| Два существительных | **DAT → AKK** | Wir zeigen **unseren Großeltern die Fotos**. |
| Только DAT — местоимение | **Местоимение первым** | Wir zeigen **ihnen die Fotos**. |
| Только AKK — местоимение | **Местоимение первым** | Wir zeigen **sie unseren Großeltern**. |
| Два местоимения | **AKK → DAT** | Wir zeigen **sie ihnen**. |

## Pułapki ⚠️

- Местоимение заменяет **всю группу**, включая артикль: `meiner Nachbarin → ihr`.
- **sie** = «её» или «их»; **ihr** = «ей»; **ihnen** = «им».
- **den** бывает AKK мужского рода **или** DAT Plural — смотри на число!
- N-Deklination: `der Student → dem Studenten / den Studenten` — окончание **-en** даже в единственном числе.
- Глагол согласуй с **подлежащим**: `du leihst`, `ihr bringt`.
- Отделяемая приставка — **в конец**: `zurückgeben → … gibt … zurück`.

**Проверка:** кому / что → окончания → форма глагола → местоимения → порядок.
