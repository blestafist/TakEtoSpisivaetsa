Conditionals.

0. Conditional (things that are true, or obvious) Present Simple + Present Simple if it rains, I take umbrella.
    
1. Conditional (things which might be true under certain condition) if + Present Simple, Future simple if the weather is good, we will go for a walk.
    
2. Conditional (hypothetical things, situations). If I won the lottery, I would buy a Ferrari. if + Past Simple, would + verb
    
3. Conditional (hypothetical situations about Past). If I had left earlier, I would have caught my bus to school. If + Past Perfect, would have + 3 forma / -ed
