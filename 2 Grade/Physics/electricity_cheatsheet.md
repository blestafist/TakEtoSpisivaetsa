## 1. Виды напряжения

Напряжение (U) — это "давление", которое заставляет электроны двигаться по проводу. Без напряжения тока нет, как вода не течёт без разницы высот.

### Постоянное напряжение (DC)

- Значение не меняется со временем
- На графике — прямая горизонтальная линия
- Примеры: батарейка 1.5В, USB 5В, аккумулятор 12В

### Переменное несинусоидальное

- Напряжение меняется, но не по синусу
- На графике — прямоугольники, пилообразные волны
- Примеры: сигналы в электронике, импульсные блоки питания

### Переменное синусоидальное

- Напряжение меняется по закону синуса — плавно растёт, падает, уходит в минус и обратно
- На графике — красивая волна
- Примеры: **обычная розетка** (220В, 50 Гц)

## 2. Переменный ток — что происходит физически

В розетке электроны не летят в одну сторону — они колеблются туда-обратно 50 раз в секунду. Несмотря на это, лампочка горит, потому что энергия передаётся всё равно.

### Ключевые понятия

**Амплитуда (U₀)** — максимальное значение напряжения. В розетке U₀ ≈ 311 В, хотя говорят "220В" — почему, объяснено ниже.

**Период (T)** — время одного полного колебания (туда и обратно). В розетке T = 0.02 с = 20 мс.

**Частота (f)** — сколько полных колебаний за одну секунду. В розетке f = 50 Гц. Связь с периодом:

```
f = 1 / T       T = 1 / f
```

**Мгновенное напряжение (u)** — значение напряжения в конкретный момент времени:

```
u = U₀ · sin(ωt)
```

где ω = 2πf — угловая частота (просто математический коэффициент).

## 3. Действующее напряжение (U_s / RMS)

### Зачем оно нужно

Переменное напряжение постоянно меняется — то 311В, то 0, то -311В. Как тогда сравнивать его с постоянным? Использовать максимум (311В) нечестно — большую часть времени напряжение меньше.

Придумали хитрое решение: **действующее напряжение** — это такое постоянное напряжение, которое выделяло бы **ровно столько же тепла** в той же лампочке за то же время.

### Для синусоиды

```
U_s = U₀ / √2 ≈ 0.707 · U₀
```

Поэтому в розетке 220В, а не 311В — 311 / √2 ≈ 220. Те самые 220В это и есть действующее значение.

### Для произвольного сигнала (как в задаче из конспекта)

Нельзя просто делить на √2 — это работает только для синусоиды. Нужно считать через работу:

1. Считаем работу на каждом участке: `W = (U² / R) · t`
2. Складываем все работы
3. Приравниваем к работе "эквивалентного" постоянного тока за весь период T
4. Находим U_s

```
W₁ + W₂ + ... = (U_s² / R) · T

U_s = √( (U₁²·t₁ + U₂²·t₂ + ...) / T )
```

### Пример из твоего конспекта

График: 4В на интервале T/3, затем 2В на T/3, затем 0В на T/3.

```
W₁ = (4²/R) · (T/3) = (16/R) · (T/3)
W₂ = (2²/R) · (T/3) = (4/R)  · (T/3)
W₃ = 0

W_total = (T/R) · (16+4)/3 = (20/3) · (T/R)

(U_s²/R) · T = (20/3) · (T/R)
U_s² = 20/3
U_s = √(20/3) ≈ 2.58 В
```

## 4. Закон Ома

### Что означает каждая буква

**I — сила тока (Амперы, А)** Сколько электрического заряда проходит через провод за секунду. Аналогия: количество воды, текущей через трубу.

**U — напряжение (Вольты, В)** "Давление", которое гонит ток. Аналогия: давление воды в трубе. Чем больше — тем сильнее течёт.

**R — сопротивление (Омы, Ω)** Насколько сильно материал мешает току течь. Аналогия: узость трубы. Тонкая труба = большое сопротивление = меньше тока.

### Формулы

```
I = U / R       (ток = напряжение / сопротивление)
U = I · R       (напряжение = ток × сопротивление)
R = U / I       (сопротивление = напряжение / ток)
```

Запоминать все три не нужно — достаточно одной, остальные выводятся за секунду.

### Пример

Лампочка с R = 484 Ом подключена к 220В. Какой ток?

```
I = U / R = 220 / 484 ≈ 0.45 А
```

## 5. Мощность (P)

### Что это такое

Мощность — это **как быстро** устройство потребляет или выделяет энергию. Единица — Ватт (Вт).

Лампочка 100Вт потребляет энергию в 10 раз быстрее, чем лампочка 10Вт. За одно и то же время она израсходует в 10 раз больше электроэнергии.

### Формулы (все три — одно и то же)

```
P = U · I           (если знаешь напряжение и ток)
P = I² · R          (если знаешь ток и сопротивление)
P = U² / R          (если знаешь напряжение и сопротивление)
```

Используй ту формулу, в которой у тебя есть нужные данные.

### Пример

Та же лампочка: U = 220В, I = 0.45А

```
P = U · I = 220 · 0.45 = 99 Вт ≈ 100 Вт
```

## 6. Работа (W)

### Что это такое

Работа — это **сколько всего** энергии потрачено за какое-то время. Единица — Джоуль (Дж).

> Мощность и работа — это НЕ одно и то же! Мощность — это скорость. Работа — это расстояние. Как скорость машины (км/ч) и пройденный путь (км).

### Связь мощности и работы

```
W = P · t
```

Работа = мощность × время. Всё просто.

### Все формулы для работы

Берёшь любую формулу мощности и дописываешь `· t`:

```
W = P · t
W = U · I · t
W = I² · R · t
W = (U² / R) · t        ← эта используется в задаче из конспекта
```

### Пример

Лампочка 100Вт горит 1 час = 3600 секунд:

```
W = P · t = 100 · 3600 = 360 000 Дж = 360 кДж
```

На счётчике дома — **киловатт-часы (кВт·ч)**. Это тоже работа, просто в других единицах:

```
1 кВт·ч = 1000 Вт × 3600 с = 3 600 000 Дж
```

## 7. Алгоритм решения задач на U_s (действующее напряжение)

Если дан график напряжения и нужно найти U_s:

1. Посмотри на график, раздели период T на участки с постоянным напряжением
2. Запиши напряжение и время для каждого участка (U₁, t₁), (U₂, t₂)...
3. Посчитай работу на каждом участке: `Wₙ = (Uₙ² / R) · tₙ`
4. Сложи все работы: `W = W₁ + W₂ + ...`
5. Приравняй: `(U_s² / R) · T = W`
6. Найди U_s: `U_s = √(W · R / T)`

Сопротивление R при этом обычно сокращается само.

## 8. Все формулы — быстрая таблица

|Что найти|Формула|Единица|
|---|---|---|
|Ток|I = U / R|А (Ампер)|
|Напряжение|U = I · R|В (Вольт)|
|Сопротивление|R = U / I|Ω (Ом)|
|Мощность|P = U·I = I²·R = U²/R|Вт (Ватт)|
|Работа|W = P·t = U·I·t = (U²/R)·t|Дж (Джоуль)|
|Период через частоту|T = 1 / f|с (секунда)|
|Частота через период|f = 1 / T|Гц (Герц)|
|U_s синусоиды|U_s = U₀ / √2 ≈ 0.707·U₀|В (Вольт)|
|U_s произвольного|U_s = √((U₁²t₁ + U₂²t₂ + ...) / T)|В (Вольт)|

## 9. Частые ошибки

- **U_s = U₀ / √2 только для синусоиды.** Для прямоугольного или другого сигнала — только через работу.
- **Работа и мощность — разные вещи.** P в Ваттах, W в Джоулях.
- **В задачах на U_s** сопротивление R почти всегда сокращается — не пугайся если его не дано.
- **Период T** на графике — это длина одного полного цикла, не половины.
