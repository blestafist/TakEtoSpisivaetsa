# Wzory — Napięcie Skuteczne / Prąd Przemienny

---

## 1. Praca elektryczna

|Wzór|Opis|
|---|---|
|W = u · j · t|praca elektryczna (ogólnie)|
|W = (u² / R) · t|praca przez opór R przy napięciu u|
|J = U / R|prawo Ohma — natężenie|
|U = J · R|prawo Ohma — napięcie|

---

## 2. Napięcie skuteczne

|Wzór|Opis|
|---|---|
|W_s = (U_s² / R) · T|praca napięcia skutecznego w okresie T|
|W_c = W_s|warunek skuteczności|
|U_s = U_0 / √2|napięcie skuteczne sinusoidy|
|U_s = √((u1²·t1 + u2²·t2 + ...) / T)|napięcie skuteczne przebiegu prostokątnego|

---

## 3. Klasyfikacja napięć

| Typ            | Opis                        | Wzór                             |
| -------------- | --------------------------- | -------------------------------- |
| Stałe (s)      | wartość stała, znak stały   | u = const                        |
| Pulsujące      | wartość zmienna, znak stały | przebieg prostokątny / trapezowy |
| Przemienne (z) | wartość i znak zmienne      | u = U_0 · sin(ωt)                |

---

## 4. Algorytm rozwiązywania

|Krok|Czynność|
|---|---|
|1|Wypisz dane i szukane (standardowe oznaczenia)|
|2|Przelicz na SI|
|3|Wypisz równania zawierające dane i szukane|
|4|Rozwiąż algebraicznie|
|5|Oblicz — wzór czysty, jednostki na końcu: `[V²·s/s = V² = V]`|
